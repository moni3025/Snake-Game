🐍 Snake Game

A classic Snake Game built using HTML, CSS, and JavaScript. Control the snake, collect apples, increase your score, and try to beat your highest score!

🎮 Live Demo

"Play Snake Game" (YOUR_LIVE_DEMO_LINK)

✨ Features

- 🎯 Interactive game interface
- 🐍 Smooth snake movement
- 🍎 Random apple generation
- 📊 Real-time score tracking
- 🏆 Highest score tracking
- ⚡ Increasing game speed as the level progresses
- ⏸️ Pause and resume functionality
- 🔄 Restart option after Game Over
- ⌨️ Keyboard controls
- 📱 Mobile-friendly control buttons

🛠️ Technologies Used

- HTML5 – Structure of the game
- CSS3 – Styling and user interface
- JavaScript – Game logic and functionality

🎮 How to Play

1. Click the Start Game button.
2. Use the arrow keys or on-screen buttons to control the snake.
3. Collect apples to increase your score.
4. Avoid hitting the walls or your own body.
5. Try to achieve the highest score!

⌨️ Controls

Key| Action
⬆️ Arrow Up| Move Up
⬇️ Arrow Down| Move Down
⬅️ Arrow Left| Move Left
➡️ Arrow Right| Move Right
Pause Button| Pause Game
